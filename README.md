# Ayser Editor Portfolio

This is a static portfolio website for a video editor/creator.

## Local preview

Open `monter.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/monter.html
```

## GitHub Pages deployment

1. Create a new GitHub repository.
2. Push the project to the repository.
3. Go to repository Settings -> Pages.
4. Select the main branch and root folder.
5. Save.

Expected URL:

```text
https://ayser-editor.github.io/montaj-portfolio
```

## Note

This project contains many video files. For best performance on GitHub Pages, consider uploading the largest videos to YouTube, Vimeo, or a CDN and linking them from the portfolio page.
